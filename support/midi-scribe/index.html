MIDI Scribe Support

Get support

We are happy to help with issues, and we appreciate feedback and feature requests. There are two ways to get support:

  • File an issue in the public MIDI Scribe GitHub issue tracker.
  • Email support@centennialoss.org.

Issues / Problems

Include as detailed a report as possible about what happened. From the app's About screen, copy the Build info section and include it with your report.

Feature Requests / General Feedback

For feature requests, describe the feature you need and how it would help. We cannot accept every request, and new features need to be useful for the broader user base rather than only solving a narrow one-off need. For general feedback, we love any and all feedback and take it seriously.

We will reply as soon as we can.
